В этом репозиторие три проекта:
1) Контроллер заряда солнечных панелей с MPPT алгоритмом (силовая плата и плата управления): Принципиальные схемы, разведеная плата управления и силовая плата, 3д модель корпуса, код прошивки микроконтроллера.
2) Ультрозвуковой дальномер: Реализовать дальномер на базе платы DE10-Lite и ультразвукового датчика расстояния HC-SR04. Код написан на SystemVerilog.
3) Лидар: реализован на отладочной плате ПЛИС. Код на VHDL.
